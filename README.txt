# Easy Autoservice - بناء APK تلقائي بدون Android Studio

هذا المشروع يبني لك APK تلقائيا على GitHub بدون تثبيت أي شيء!

## الطريقة (3 دقائق):

1. اذهب الى https://github.com/new
   - اسم المستودع: easy-autoservice
   - اختر Public
   - Create repository

2. ارفع كل الملفات من هذا المجلد الى GitHub:
   - اضغط Add file -> Upload files
   - اسحب كل الملفات (www folder + .github folder + capacitor.config.json + package.json)
   - Commit

3. اذهب الى تبويب Actions في GitHub
   - ستجد Build Android APK يعمل تلقائيا
   - انتظر 3-4 دقائق
   - اضغط على آخر عملية -> ستجد في الأسفل EasyAutoservice-APK -> Download
   - ستحصل على app-debug.apk جاهز للتثبيت!

## طريقة أسرع بدون GitHub:

استخدم هذه المواقع التي لا تحتاج manifest:

1. https://www.appsgeyser.com
   - Create App -> Website
   - الصق: https://easyautoservice.netlify.app
   - Download APK

2. https://pwa2apk.com
   - الصق رابطك -> Generate APK

3. https://appmaker.xyz
   - Convert Website to APK
